# Диагностика ошибок

Сообщение об ошибке содержит код и, для серверных запросов, идентификатор request_id. Сохраните оба значения, время возникновения и выполненное действие. Для фоновых операций откройте журнал импорта, экспорта, автоматизации или интеграции: сообщение в нём обычно точнее краткого уведомления на экране. Не отправляйте в поддержку пароли, API-ключи, резервные коды TOTP и полные файлы с персональными данными без согласованного защищённого канала.

| Код | Что означает | Что проверить |
| --- | --- | --- |
| AUTH-401 | Неверные данные входа или истёкший сеанс | Войдите заново; при необходимости сбросьте пароль |
| AUTH-403 | Нет доступа к выбранному пространству | Статус приглашения и активность пользователя |
| AUTH-429 | Пять неудачных попыток входа | Подождите 15 минут, затем используйте верные данные |
| IMP-101 | Не удалось прочитать структуру CSV | UTF-8, заголовки, разделитель и кавычки |
| IMP-102 | Значение не подходит типу поля | Сопоставление столбцов и формат даты |
| IMP-201 | Превышен лимит активных контактов | Архивируйте лишнее или повысьте тариф |
| EXP-403 | Нет разрешения на экспорт | Роль и contacts.export |
| EXP-413 | Более 50 000 строк в файле | Разбейте выборку фильтрами |
| EXP-429 | Пять заданий за 24 часа | Дождитесь освобождения скользящей квоты |
| API-401 | Ключ недействителен или отозван | Срок, заголовок Authorization, статус пользователя |
| API-403 | Не хватает scope или прав на запись | Scopes ключа и видимость карточки |
| API-429 | Превышена API-квота | Retry-After и статистика использования |
| AUT-409 | Получатель задачи отключён | Измените правило или активируйте пользователя |
| AUT-422 | Условие или поле больше не существует | Откройте и сохраните правило после исправления |

| INT-422 | Некорректное тело события | event_type, external_id и обязательные поля |
| INT-502 | Ошибка связи с внешним сервисом | Статус OAuth и журнал интеграции |

## Ошибки импорта и экспорта

При IMP-101 откройте CSV в текстовом редакторе и проверьте первую строку. Каждая запись должна иметь одинаковое число столбцов; запятые внутри значений заключаются в кавычки. Ошибки отдельных строк не отменяют уже созданные записи. Скачайте файл ошибок в журнале импорта и повторите только исправленные строки.

При EXP-403 кнопка может вообще не отображаться. Владелец и администратор имеют право на экспорт по умолчанию; менеджеру его включают отдельно, наблюдателю оно недоступно. При EXP-413 примените фильтр по дате или ответственному так, чтобы каждый файл содержал до 50 000 строк. Неудавшееся задание не расходует дневную квоту, готовая ссылка действует 24 часа.

## Ошибки API и интеграций

Ответ 429 API всегда следует обрабатывать с учётом Retry-After. Частые немедленные повторы усугубляют перегрузку. Если запрос возвращает 404 на существующий ID, проверьте видимость записи для пользователя, создавшего ключ; API скрывает недоступную карточку так же, как отсутствующую. Ответ 422 указывает на неверные поля или схему, а 409 при POST с Idempotency-Key — на повтор ключа с другим телом.

Для исходящего webhook проверьте HTTPS-адрес, доступность принимающего сервера и ответы 2xx. NexaCRM повторяет доставку через 1, 5 и 30 минут после неудачи; дальнейшую отправку запускают вручную в журнале. События могут прийти не по порядку. Если автоматизация не сработала, проверьте, что правило было включено до события и его условия действительно выполнялись.

Если ошибка сохраняется, приложите код, request_id, идентификатор задания или записи, примерное время и ожидаемый результат. Этого обычно достаточно для диагностики без передачи секретов.
