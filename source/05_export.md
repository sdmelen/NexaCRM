# Экспорт компаний и контактов

Экспорт создаёт CSV с клиентскими данными для резервной копии, анализа или переноса в другую систему. Компании и контакты выгружаются отдельными заданиями. CSV содержит идентификаторы NexaCRM, стандартные и выбранные пользовательские поля, ответственного и дату изменения. Заметки, задачи и история сделки в выгрузку клиентского списка не входят; для них используйте соответствующие разделы интерфейса или API при наличии прав.

## Кто может выгружать данные

Владелец и администратор имеют разрешение contacts.export по умолчанию. Администратор может отдельно включить его менеджеру в «Настройки → Пользователи → Разрешения». Наблюдателю экспорт недоступен. Разрешение позволяет выгружать только те карточки, которые пользователь видит в интерфейсе: назначенные ему и общие для менеджера, все записи для владельца и администратора. Фильтр списка дополнительно сужает выгрузку, но не расширяет доступ.

Экспорт является чувствительным действием и записывается в журнал аудита: кто запустил задание, какой тип записей выбрал, сколько строк вошло в файл и когда файл был скачан. Если менеджеру больше не нужен доступ, снимите contacts.export; уже скачанную копию таким образом отозвать нельзя.

## Как создать выгрузку

1. Откройте «Клиенты → Контакты» или «Клиенты → Компании». При необходимости задайте поиск и фильтры по ответственному, статусу или пользовательским полям.
2. Нажмите «Экспорт» и выберите «Текущее представление» либо «Все доступные записи». Для архивных записей отдельно включите переключатель «Включить архив».
3. Отметьте поля и нажмите «Создать файл». Система добавляет ID записи всегда, даже если его не было в выборе столбцов: он помогает при повторном импорте и сверке данных.
4. В «Клиенты → Экспорт → Задания» дождитесь состояния «Готово» и скачайте CSV. Файл кодируется в UTF-8, первая строка содержит заголовки, даты записаны в ISO 8601.

На всех тарифах один файл содержит максимум 50 000 строк. Если результат больше, разбейте его фильтрами, например по дате изменения или ответственному; система не создаёт автоматически несколько файлов. В рабочем пространстве можно запустить не более пяти экспортных заданий за скользящие 24 часа. Неудавшееся задание не расходует квоту. Ссылка на готовый файл действует 24 часа, после чего задание можно запустить заново при наличии квоты.

## Важные особенности

Снимок данных фиксируется в момент начала обработки. Изменения, внесённые после запуска, появятся только в следующей выгрузке. Если сотрудник утратил доступ к записи до формирования файла, эта запись исключается. При скачивании NexaCRM повторно проверяет разрешение contacts.export; после его отзыва файл из интерфейса недоступен.

Тарифный лимит контактов относится к активным контактам, но архив можно включить в экспорт. Массовая выгрузка сама по себе не удаляет и не изменяет записи. Если кнопка «Экспорт» не видна, проверьте роль и разрешение. Код EXP-403 означает отсутствие доступа, EXP-429 — исчерпание квоты заданий, EXP-413 — превышение размера одного файла. Для передачи файла за пределы компании соблюдайте внутренние правила обработки персональных данных.
