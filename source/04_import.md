# Импорт компаний и контактов

Импорт помогает перенести клиентскую базу из таблицы или другой CRM. NexaCRM принимает CSV в кодировке UTF-8 с заголовками в первой строке. Один файл может содержать до 20 МБ и 50 000 строк данных. Импорт выполняется как фоновое задание; закрытие страницы не прерывает обработку. Число активных контактов после загрузки не может превысить лимит тарифа.

## Подготовка файла

Экспортируйте исходные данные в CSV с разделителем запятая или точка с запятой. Мастер определяет разделитель автоматически, а на шаге проверки его можно поменять. Даты указывайте в формате ГГГГ-ММ-ДД; телефоны лучше хранить как текст с кодом страны. Для контакта обязательно заполнить имя или фамилию, для компании — название. Столбцы с пользовательскими полями должны соответствовать существующим полям NexaCRM по типу: число не загрузится в поле «Дата».

Если нужно связать контакт с компанией, добавьте столбец «Компания». При совпадении названия с существующей компанией контакт привязывается к ней; если совпадений несколько, строка получает ошибку сопоставления. Чтобы избежать неоднозначности, сначала импортируйте компании, затем контакты со столбцом «ID компании» из экспортированного или подготовленного списка. Строки с неизвестным ID компании не создают новую компанию автоматически.

## Запуск импорта

1. Откройте «Клиенты → Импорт» и выберите тип данных: «Контакты» или «Компании». В одном задании типы не смешиваются.
2. Загрузите CSV и проверьте кодировку, разделитель и пример первых строк. Если русские буквы отображаются неверно, пересохраните файл в UTF-8.
3. Сопоставьте столбцы с полями NexaCRM. Неиспользуемые столбцы можно пропустить. Выберите ответственного для новых записей; если поле «Ответственный» содержится в файле, его адрес электронной почты должен соответствовать активному пользователю.
4. Выберите действие при совпадении: «Пропустить», «Обновить пустые поля» или «Создать отдельную запись». Совпадения определяются по правилам поиска дубликатов. Для обновления существующей карточки у запускающего пользователя должно быть право её редактировать.
5. Проверьте предпросмотр и нажмите «Начать импорт». Статус и файл с ошибочными строками доступны в журнале импорта 30 дней.

Импортировать могут владелец и администратор. Менеджеру администратор может выдать разрешение contacts.import; тогда менеджер создаёт записи в своей области видимости. Наблюдателю импорт недоступен. При варианте «Обновить пустые поля» система не перезаписывает заполненные значения, не меняет владельца существующей карточки и не снимает ограничение видимости.

## Результат и исправление ошибок

Статус показывает количество созданных, обновлённых, пропущенных и ошибочных строк. Успешные строки не откатываются, даже если другие строки не прошли проверку. Скачайте CSV ошибок, исправьте исходный файл и повторно загрузите только проблемные строки. Не запускайте повторно весь файл с режимом «Создать отдельную запись», иначе получите новые дубликаты.

Коды IMP-101 и IMP-102 означают неверную структуру CSV или неподходящий тип поля; IMP-201 указывает на достижение лимита активных контактов. Если задание долго остаётся в состоянии «В очереди», проверьте его позже: параллельно в одном рабочем пространстве выполняется только один импорт. Удаление задания из журнала не удаляет созданные записи.
